# Project Roadmap

## Current Stage

Core backend for a restaurant reservation management system.

Implemented features:

* Table management and filtering
* Reservation creation and cancellation
* Group (multi-table) reservations
* Table availability search
* Reservation timeline for daily overview
* Table recommendation algorithm
* Reservation rules validation
* Dashboard statistics API
* Reservation search with pagination and sorting
* Restaurant configuration API
* Swagger / OpenAPI documentation
* Docker containerization
* Health check endpoint
* API versioning

---

## Next Features

Potential improvements for future iterations:

* Visual restaurant layout with table positioning
* Reservation update API
* Automatic reservation completion
* Advanced recommendation scoring
* Table proximity search (nearest tables)

---

## Infrastructure Improvements

* Automated tests (unit + integration)
* CI/CD pipeline
* Monitoring and logging improvements
